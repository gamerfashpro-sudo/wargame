# 1. КОНЦЕПЦИЯ ИГРЫ

Создай оригинальную военную стратегию-песочницу с элементами градостроительства, экономики, логистики и масштабных сражений.

Основной источник вдохновения — Roblox City Wars от Ostro Games.

Однако:
- Не копируй оригинальные модели, текстуры, интерфейс, код или другие защищённые материалы.
- Не используй название City Wars в качестве названия нашего проекта.
- Создай собственный визуальный стиль и собственную игровую идентичность.
- Используй похожие концепции и механики, но реализуй их самостоятельно.

Игрок должен иметь возможность самостоятельно развивать государство, строить города, создавать инфраструктуру, управлять армией, воевать с другими странами или просто экспериментировать в свободной песочнице.

Это игра, в которую можно заходить ради удовольствия, а не ради обязательного прохождения кампании.

## Основные направления игры

1. Строительство и развитие государства.
2. Экономика и производство ресурсов.
3. Логистика и транспортировка грузов.
4. Военная техника и вооружение.
5. Сражения с искусственным интеллектом.

# 2. ТЕХНОЛОГИИ

Основной движок: Unity 6.

Используй:
- Unity 6 LTS или актуальную стабильную LTS-версию.
- C#.
- Universal Render Pipeline (URP).
- Input System.
- TextMeshPro.
- Cinemachine, если действительно необходимо.
- ScriptableObjects для конфигурации игровых объектов.
- Unity AI Navigation для навигации ботов.
- Addressables только при реальной необходимости.

Не подключай десятки сторонних библиотек.

Предпочитай встроенные возможности Unity и собственные небольшие системы.

Все зависимости должны быть понятными, стабильными и необходимыми.

## Требования к запуску

Игра должна собираться в Windows Standalone Build.

Итоговая структура:

WARGAME/
  WARGAME.exe
  WARGAME_Data/
  UnityPlayer.dll
  MonoBleedingEdge/
  остальные необходимые файлы Unity

Пользователь должен запускать игру двойным нажатием на EXE.

Не требуй от конечного игрока:
- Установки Unity.
- Установки Visual Studio.
- Установки Python.
- Установки Git.
- Установки дополнительных игровых движков.
- Ручной установки библиотек.

Все необходимые игровые компоненты должны поставляться вместе со сборкой.

Предусмотри возможность создания ZIP-архива с готовой игрой.
